# Winter Duel — окружение поля

Существующий проект Unity **6000.3.10f1**, Universal Render Pipeline / 2D Renderer.
Рабочая сцена: **`Assets/Scenes/WinterField.unity`**. Она сохранена и включена
единственной сценой в Build Settings. `SampleScene` и ресурсы шаблона Unity оставлены
как исходные файлы проекта.

Откройте WinterField и нажмите Play: появится спокойный снегопад. Android настроен
на горизонтальную ориентацию. В сцене есть статичные персонажи и макет HUD;
полноценные игровые механики пока не добавлены.

## Статичные персонажи и HUD

Опорное разрешение интерфейса — **2340×1080**, соотношение сторон **13:6**.
Существующие небо, дымка, палитра, лес и рельеф сохранены.

| Объект | Ручная настройка |
| --- | --- |
| Characters / Local Player - Teal | Transform: положение, общий масштаб и наклон на снегу; свой игрок слева, X=−8.5 |
| Characters / Opponent - Red | Transform: противник справа, X=17; в начальном кадре полностью скрыт |
| Персонаж / Visual | SpriteRenderer: спрайт и Flip X; Transform: равномерный масштаб изображения |
| HUD / Canvas Scaler | Scale With Screen Size, Reference Resolution 2340×1080, Match 0.5 |
| HUD / Safe Area | ScreenSafeArea: привязка к Screen.safeArea устройства |
| Safe Area / HUD Margins | RectTransform: отступы внутри безопасной области — 64 по бокам, 48 сверху и снизу |
| HUD Margins / Local Indicators или Opponent Indicators | Health / Indicator: Slider Value 0–100; Warmth / Indicator: Slider Value 0–50 |
| HUD Margins / Action Buttons | HudActionSelection: выбранная кнопка и цвета нормального/выбранного состояния |
| HUD Margins / Action Buttons / Snowball, Ice Snowball, Restore Warmth | Обычные Button с буквами С / Л / Т; 144×144, промежутки 24 |
| HUD Margins / Menu | Кнопка ≡, 88×80; обработчик открытия меню пока отсутствует |
| EventSystem | InputSystemUIInputModule; сохранённые ссылки на UI-действия существующего InputSystem_Actions.inputactions |

Префабы: `Assets/Prefabs/Characters/TealStaticCharacter.prefab`,
`Assets/Prefabs/Characters/RedStaticCharacter.prefab` и `Assets/Prefabs/UI/DuelHud.prefab`.
Корень персонажа расположен между точками контакта подошв со снегом. При импорте
PNG задан соответствующий pivot; прозрачные поля изображения не влияют на точку
опоры. Высота видимой фигуры — около 3 мировых единиц при высоте кадра 12,
то есть примерно четверть экрана. Сценический наклон подогнан под поверхность;
для изменения размера используйте равномерный Scale корня персонажа. При переносе
в другую точку поля вручную согласуйте Y и наклон со снежным краем.

Исходные PNG скопированы без редактирования в `Assets/Art/Characters/`.
Бирюзовый персонаж обращён вправо, красный — влево через Flip X.
Animator, Rigidbody2D, поведение персонажей и боевые коллайдеры не добавлены.

Все элементы HUD сохранены как обычные UI-объекты. Шкалы не имеют ручек,
`Interactable=false`, переходы цвета отключены, графика шкал не перехватывает
касания. Значения задаются напрямую в Slider Inspector и не меняются скриптом.
Кнопки лишь меняют выделение; по умолчанию выбрана С. Canvas работает в
Screen Space - Overlay и не привязан к игровой камере. Ни персонажи, ни HUD
не создаются кодом при запуске.

Шрифт — DejaVu Sans с поддержкой З, Т, С, Л и ≡. Файл и лицензия находятся в
`Assets/Fonts/`. Два новых компонента — только `HudActionSelection` и `ScreenSafeArea`.

Проверено в Play Mode через Unity MCP: реальные события указателя переключают
С → Л → Т → С; значения четырёх шкал после кликов остаются прежними. Проверены
диапазоны, отсутствие ручек и перехвата касаний, скрытие противника за камерой,
противоположное направление спрайтов, неподвижность HUD при смещении камеры
и попадание кнопок в безопасную область. Ошибка контакта подошв с PolygonCollider2D
снега меньше 0.0002 мировой единицы. Префабы и ссылки повторно проверены после
сохранения и открытия сцены.

Game View настроен на 2340×1080. В этой среде Unity сообщает 128 МБ видеопамяти
и автоматически уменьшает его render target примерно до 1016×469; это ограничение
предпросмотра редактора. Поэтому дополнительно выполнен полноценный рендер в
RenderTexture **2340×1080**, с Canvas того же размера и Scale=1. Для этого на время
экспорта HUD переключался в Screen Space - Camera; после экспорта восстановлен
Screen Space - Overlay. Файл не является увеличенным снимком маленького окна:
[результат 2340×1080](Documentation/StaticPlayersHud-2340x1080.png).
Для удобной работы в редакторе оставлен предпросмотр 13:6 без предупреждений
о видеопамяти. На физическом Android-устройстве безопасная область и касания
пока не проверялись.

Камера: Orthographic Size = 6, Y = −0.25. Ширина обзора составляет 21.33 единицы
при 16:9 и 26.67 при 20:9 (на 20% больше первоначального обзора). Небо — вечерний
градиент с лёгкой статичной дымкой, настраиваемый в материале EveningSky.
Снежинки имеют размер 0.055–0.105,
начальную непрозрачность 0.85–1 и время жизни 28–34 секунды; частота появления
сохранена на уровне 8 частиц/с. Эмиттер поднят до Y=6.4 для нового обзора.

## Вечернее небо и дымка

Небо — сохранённый Quad 80×30 с материалом
`Assets/Materials/Environment/EveningSky.mat` и шейдером
`Assets/Shaders/Environment/WinterSky.shader`. Новых растровых картинок нет.
Верхний цвет — приглушённый синий (0.34, 0.40, 0.52), средний — сине-серый
(0.55, 0.59, 0.67), горизонт — серо-лавандовый (0.72, 0.70, 0.76).

Все параметры доступны в Inspector материала:

- `Upper Evening Blue`, `Middle Blue Gray`, `Horizon Gray Lavender` — цвета неба.
- `Horizon / Middle / Top Height` — высоты цветовых переходов в мировых единицах.
- `Haze Color`, `Haze Opacity` — цвет и интенсивность дымки; текущая прозрачность 0.065.
- `Main Haze Height` — высота основной полосы, сейчас Y=0.25.
- `Haze Edge Softness` — мягкость размытых краёв, сейчас 0.45.
- `Haze Band Spacing`, `Haze Edge Irregularity` — расстояние и неровность трёх широких полос.

Дымка вычисляется вместе с небом без анимации и использования времени.
Порядок отрисовки неба −100: дымка всегда за лесом (−20), дальним снегом (0),
ближним снегом (10) и снежинками (30). Это фон, а не эффект поверх игровой сцены.
При расширении камеры за пределы текущего неба увеличьте Quad равномерно по нужной
оси: высоты градиента и дымки заданы в мировых координатах и от масштаба Quad не зависят.

Передний снег: мягкий тёплый белый у поверхности (0.955, 0.95, 0.925) с лёгким
холодным оттенком к низу. Дальний снег: серо-лавандовый (0.70, 0.70, 0.775).

Параметры **SnowTerrain** пересоздают форму прямо в редакторе:

- `Width` — полная ширина; сейчас 40 единиц.
- `Surface Height` — базовая высота верхнего края в локальных координатах.
- `Bottom Height` — нижняя граница заливки; сейчас −8 при нижней границе камеры −6.25.
- `Amplitude` — высота отклонений; 0.40 у дальнего и 0.34 у ближнего слоя.
- `Smoothness` — длина широких изгибов; большее значение делает их протяжённее.
- `Segments` — детализация; сейчас 240 сегментов на всю ширину.
- `Seed` — фиксированный характер изгибов; 139 / 7341.
- `Surface Color`, `Bottom Color` — цвета плавной заливки.
- `Snow Material`, `Sorting Order` — материал и порядок отрисовки.
- `Generate Collider` — включён только у ближнего холма.

Геометрия генерируется одним компонентом `Assets/Scripts/Environment/SnowTerrain.cs`.
Сама сцена состоит из сохранённых объектов и штатных компонентов, а не создаётся
при запуске. Метод `GetWorldSurfacePoint(localX)` возвращает мировую точку на
фактической ломаной поверхности для будущего размещения персонажей. Передавать
нужно X в локальных координатах объекта холма. Коллайдер статический, замкнутый
до нижней границы снега; Rigidbody2D для земли не нужен.

## Лес и перекрытие

Исходник последнего PNG леса без изменений: `ArtSource/Environment/Forest.original.png`.
Импортированный PNG: `Assets/Art/Environment/Forest.png`. Второе вложение в проект
не добавлено. У исходника уже есть альфа-канал: пиксель (0, 0) имеет RGBA (0, 0, 0, 0),
861858 пикселей полностью прозрачны. В Texture Importer включено Alpha Is Transparency,
используется Full Rect, сжатие отключено для сохранения края прозрачности.

Масштаб елей равномерный: (1.2, 1.2, 1.2), центр полосы поднят до Y=1.35,
чтобы маленькие ели были видны кронами и нижними ветвями над дальним холмом.
Центральная полоса имеет ширину 26.064
единицы; слева и справа сохранены дополнительные копии той же полосы. Подложка
шириной 100 уходит от Y=−2.3 до −10.5 и перекрывается с плотной нижней частью
изображения, заканчивающейся на Y=−2.994. Цвет подложки согласован с сумеречной
палитрой материала Forest (0.25, 0.29, 0.37). Её верх скрыт лесом и дальним снегом.
Поэтому понижение снежного края не открывает пустоту под картинкой.

`Assets/Shaders/Environment/ForestPalette.shader` переводит яркость исходного PNG
в диапазон между тёмным и светлым цветом материала Forest, сохраняя детали,
различимость рядов и прозрачность. Сам PNG и исходник в ArtSource не изменены.

При значительном изменении камеры или размеров поля нужно согласовать ширину
холмов, низ заливки, подложку и ширину эмиттера. Текущая камера имеет высоту 12,
а снег и эмиттер — ширину 40. Не растягивайте деревья только по одной оси.

## Проверка

Палитра и небо настроены и проверены в открытом Unity Editor через Unity MCP
(`tools/call`, включая `script_eval` и `capture_game_view`):

- Game View в Play Mode: 16:9 (1600×900) и 20:9 (1600×720).
- Оба шейдера поддерживаются текущим рендерером; ShaderUtil не возвращает ошибок
  или предупреждений. Все материалы и ссылки назначены; дымка рисуется за всеми
  слоями леса и снега. Console без ошибок и предупреждений.
- Небо видно через прозрачный лес; чёрного фона, открытых стыков и плоской
  видимой верхней границы подложки нет. Снег заполняет оба слоя до низа.
- Повторная генерация даёт идентичные вершины; коллайдер использует те же точки.
- 41 вертикальный Physics2D raycast по X от −14 до 14 попал в ближний снег;
  максимальная разница с API поверхности меньше 0.0006 единицы.
- Дальний холм не имеет Collider2D. Материалы назначены всем Renderer.
- После настройки яркости и увеличения обзора в системе было 251 частица;
  вертикальная скорость отрицательная (примерно −0.42…−0.62 единицы/с).
- Сцена повторно открыта; ошибок компиляции и отсутствующих компонентов нет.
- URP MSAA установлен в 4 для сглаживания краёв рельефа.

Снимки Game View: [16:9](Documentation/WinterField-16x9.png) и
[20:9](Documentation/WinterField-20x9.png). Ширина для 24:9 рассчитана с запасом,
но визуально проверены именно 16:9 и 20:9.

На физическом Android-устройстве сцена пока не проверялась; APK не собирался.
Броски, прицеливание, Bluetooth, ветер, расход тепла, урон, анимации и деформации
снега отсутствуют. Шкалы являются настраиваемыми UI-индикаторами.
