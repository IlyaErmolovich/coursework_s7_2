# Winter Duel — окружение поля

Существующий проект Unity **6000.3.10f1**, Universal Render Pipeline / 2D Renderer.
Рабочая сцена: **`Assets/Scenes/WinterField.unity`**. Она сохранена и включена
единственной сценой в Build Settings. `SampleScene` и ресурсы шаблона Unity оставлены
как исходные файлы проекта.

Откройте WinterField и нажмите Play: появится спокойный снегопад. Android настроен
на горизонтальную ориентацию. Механики игры пока не добавлены.

Камера: Orthographic Size = 6, Y = −0.25. Ширина обзора составляет 21.33 единицы
при 16:9 и 26.67 при 20:9 (на 20% больше первоначального обзора). Небо — вечерний
градиент с лёгкой статичной дымкой, настраиваемый в компонентах объектов неба.
Снежинки имеют размер 0.055–0.105,
начальную непрозрачность 0.85–1 и время жизни 28–34 секунды; частота появления
сохранена на уровне 8 частиц/с. Эмиттер поднят до Y=6.4 для нового обзора.

## Объекты и Inspector

| Static Haze - vertex transparency / VertexHaze | Цвет, прозрачность, высота, расстояние между полосами и мягкость краёв дымки |
| Environment / 01 - Background Forest | Положение леса; три SpriteRenderer расширяют поле по горизонтали |

| Forest Base / MeshRenderer / материал ForestBase | Цвет подложки под непрозрачным низом леса |

## Вечернее небо и дымка

Небо — сохранённый объект с MeshFilter, MeshRenderer и компонентом
`Assets/Scripts/Environment/VertexGradientSky.cs`. Сетка размером 80×30 имеет
258 вершин с цветами. Материал `Assets/Materials/Environment/EveningSky.mat`
использует штатный `Universal Render Pipeline/2D/Sprite-Unlit-Default`.
Собственных shader-файлов в этой версии нет. Картинки для неба и дымки не нужны.
Верхний цвет — приглушённый синий (0.34, 0.40, 0.52), средний — сине-серый
(0.55, 0.59, 0.67), горизонт — серо-лавандовый (0.72, 0.70, 0.76).

Параметры **VertexGradientSky** доступны в Inspector объекта неба:

- `Upper Color`, `Middle Color`, `Horizon Color` — цвета неба.
- `Horizon / Middle / Upper Height` — высоты цветовых переходов.
- `Width`, `Bottom Height`, `Ceiling Height` — покрытие фона.
- `Vertical Segments` — детализация плавного градиента, сейчас 128.

Параметры **VertexHaze** доступны на дочернем объекте Static Haze:

- `Haze Color`, `Opacity` — цвет и интенсивность; текущая прозрачность 0.065.
- `Height` — высота основной полосы, сейчас Y=0.25.
- `Edge Softness` — мягкость размытых краёв, сейчас 0.45.
- `Band Spacing`, `Edge Irregularity` — расстояние и неровность трёх широких полос.
- `Width`, `Horizontal Segments`, `Edge Segments` — ширина и детализация сетки.

Дымка — сетка из трёх широких полос с плавно меняющейся прозрачностью вершин,
без анимации и использования времени. Сейчас у неё 8127 вершин.
Небо рисуется с порядком −100, дымка с порядком −90, за лесом (−20), дальним снегом (0),
ближним снегом (10) и снежинками (30). Это фон, а не эффект поверх игровой сцены.
При расширении камеры меняйте Width и границы сеток в компонентах. Все размеры
заданы в локальных единицах; объекты неба имеют единичный масштаб и Y=0.
Цвета, формы и прозрачность пересчитываются при изменении Inspector и открытии
сцены. Компоненты генерируют только свои сетки и не создают объекты при запуске.

Передний снег: мягкий тёплый белый у поверхности (0.955, 0.95, 0.925) с лёгким
холодным оттенком к низу. Дальний снег: серо-лавандовый (0.70, 0.70, 0.775).

Параметры **SnowTerrain** пересоздают форму прямо в редакторе:

- `Width` — полная ширина; сейчас 40 единиц.
- `Surface Height` — базовая высота верхнего края в локальных координатах.
- `Bottom Height` — нижняя граница заливки; сейчас −8 при нижней границе камеры −6.25.
- `Amplitude` — высота отклонений; 0.40 у дальнего и 0.34 у ближнего слоя.
- `Smoothness` — длина широких изгибов; большее значение делает их протяжённее.
- `Segments` — детализация; сейчас 240 сегментов на всю ширину.
- `Seed` — фиксированный характер изгибов; 139 / 7341.
- `Surface Color`, `Bottom Color` — цвета плавной заливки.
- `Snow Material`, `Sorting Order` — материал и порядок отрисовки.
- `Generate Collider` — включён только у ближнего холма.

Геометрия генерируется одним компонентом `Assets/Scripts/Environment/SnowTerrain.cs`.
Сама сцена состоит из сохранённых объектов и штатных компонентов, а не создаётся
при запуске. Метод `GetWorldSurfacePoint(localX)` возвращает мировую точку на
фактической ломаной поверхности для будущего размещения персонажей. Передавать
нужно X в локальных координатах объекта холма. Коллайдер статический, замкнутый
до нижней границы снега; Rigidbody2D для земли не нужен.

## Лес и перекрытие

Исходник последнего PNG леса без изменений: `ArtSource/Environment/Forest.original.png`.
Импортированный PNG: `Assets/Art/Environment/Forest.png`. Второе вложение в проект
не добавлено. У исходника уже есть альфа-канал: пиксель (0, 0) имеет RGBA (0, 0, 0, 0),
861858 пикселей полностью прозрачны. В Texture Importer включено Alpha Is Transparency,
используется Full Rect, сжатие отключено для сохранения края прозрачности.

Масштаб елей равномерный: (1.2, 1.2, 1.2), центр полосы поднят до Y=1.35,
чтобы маленькие ели были видны кронами и нижними ветвями над дальним холмом.
Центральная полоса имеет ширину 26.064
единицы; слева и справа сохранены дополнительные копии той же полосы. Подложка
шириной 100 уходит от Y=−2.3 до −10.5 и перекрывается с плотной нижней частью
изображения, заканчивающейся на Y=−2.994. Цвет подложки согласован с сумеречной
палитрой материала Forest (0.25, 0.29, 0.37). Её верх скрыт лесом и дальним снегом.
Поэтому понижение снежного края не открывает пустоту под картинкой.

`Assets/Art/Environment/Forest.Evening.png` — отдельная копия с запечённой вечерней
палитрой прежнего материала Forest. Оригинальные Forest.png и исходник в ArtSource
не изменены. Размеры и альфа-канал копии точно совпадают с оригиналом. Все три
SpriteRenderer используют эту копию и стандартный материал Forest. Палитра рядов
теперь фиксирована в PNG; независимое перекрашивание рядов потребует новой копии.

При значительном изменении камеры или размеров поля нужно согласовать ширину
холмов, низ заливки, подложку и ширину эмиттера. Текущая камера имеет высоту 12,
а снег и эмиттер — ширину 40. Не растягивайте деревья только по одной оси.

## Проверка

Палитра и небо настроены и проверены в открытом Unity Editor через Unity MCP
(`tools/call`, включая `script_eval` и `capture_game_view`):

- Game View в Play Mode: 16:9 (1600×900) и 20:9 (1600×720).
- Все материалы сцены используют штатные шейдеры Unity/URP, зависимостей от
  собственных shader-файлов нет. Все материалы и ссылки назначены; дымка рисуется
  за всеми слоями леса и снега. Console без ошибок и предупреждений.
- Небо видно через прозрачный лес; чёрного фона, открытых стыков и плоской
  видимой верхней границы подложки нет. Снег заполняет оба слоя до низа.
- Повторная генерация даёт идентичные вершины; коллайдер использует те же точки.
- 41 вертикальный Physics2D raycast по X от −14 до 14 попал в ближний снег;
  максимальная разница с API поверхности меньше 0.0006 единицы.
- Дальний холм не имеет Collider2D. Материалы назначены всем Renderer.
- После настройки яркости и увеличения обзора в системе было 251 частица;
  вертикальная скорость отрицательная (примерно −0.42…−0.62 единицы/с).
- Сцена повторно открыта; ошибок компиляции и отсутствующих компонентов нет.
- URP MSAA установлен в 4 для сглаживания краёв рельефа.

Снимки Game View: [16:9](Documentation/WinterField-16x9.png) и
[20:9](Documentation/WinterField-20x9.png). Ширина для 24:9 рассчитана с запасом,
но визуально проверены именно 16:9 и 20:9.

На физическом Android-устройстве сцена пока не проверялась; APK не собирался.
Персонажи, броски, Bluetooth, ветер, здоровье, UI и деформации снега отсутствуют
согласно объёму этого этапа.

## Git

с собственными шейдерами сохранена в **codex/winter-field-environment**, коммит

ветку через `git switch codex/winter-field-environment`, затем откройте проект.

`coursework_s7` и его прежние изменения не включены в историю этого репозитория.

исключены через `.gitignore`.
