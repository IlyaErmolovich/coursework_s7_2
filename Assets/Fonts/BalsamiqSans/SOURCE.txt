The original Bold TTF is unchanged (OS/2 weight 700, face style Bold).
Menu buttons use TextMeshProUGUI with BalsamiqSans-Bold-SDF.asset, a static
1024x1024 SDF atlas baked at 64pt with padding 8 (SDFAA), ASCII 32-126 and
Cyrillic U+0400-045F: 191 characters, no missing glyphs.
Shared material Assets/Materials/Menu/BalsamiqSans-Bold-Menu.mat:
Face Dilate 0.075, Outline 0, Underlay off. No synthetic Bold on top of the
actual Bold glyphs. Font size 58, no auto-fit. Standard TMP Essential Resources
supply the SDF shader. Other pre-existing connection labels retain Unity UI Text.
