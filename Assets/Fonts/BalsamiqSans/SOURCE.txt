Unity's TrueType FontImporter creates the dynamic Font asset from this original
Bold TTF. The font data stays embedded so Cyrillic glyphs are available on Android.
Main menu labels use Unity UI Text with the Bold face, FontStyle.Bold, a shared
size of 58 and geometry alignment. Auto-fit is disabled.
